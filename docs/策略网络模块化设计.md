# 策略网络模块化设计

## 参考实现

- [robomimic `obs_nets.py`](https://github.com/ARISE-Initiative/robomimic/blob/master/robomimic/models/obs_nets.py)：`RNN_MIMO_MLP`
  将 observation encoder、RNN 和 output head 分开；`GMMActorNetwork`
  由 mixture logits、每个 mode 的 mean/log-std 和
  [`GMMDistribution`](https://github.com/ARISE-Initiative/robomimic/blob/master/robomimic/models/distributions.py) 组成。
- [robomimic `policy_nets.py`](https://github.com/ARISE-Initiative/robomimic/blob/master/robomimic/models/policy_nets.py)：GMM policy head 的调用方式。
- [Stable-Baselines3 `distributions.py`](https://github.com/DLR-RM/stable-baselines3/blob/master/stable_baselines3/common/distributions.py)：SAC 的
  squashed Gaussian action head 使用 `tanh`，再按 action-space 的
  `scale/bias` 映射；这部分由 `SquashedGaussianHead` 独立承担。
- [PyTorch distributions](https://pytorch.org/docs/stable/distributions.html)：
  LSTM-GMM 使用 `MixtureSameFamily(Categorical, Independent(Normal))`，
  训练目标是动作负对数似然，而不是把 GMM 当作额外的 MLP 层。

## 当前模块

`training/algorithm/base_policy.py` 负责两种基准策略，`training/utils/policy_utils.py`
负责时序输入和 CNN-GRU 编码器：

1. `TemporalConvGRUEncoder`：输入 `(B,T,D)`，先用保持长度的 `Conv1d`
   提取局部时间模式，再由 GRU 汇总长时依赖；输出 `[h_norm, s_t]`，保持
   原有残差 SAC 的基座表示契约。
2. `SquashedGaussianHead`：只处理动作分布、重参数化采样、tanh 修正项和
   action-space 映射，不依赖具体 encoder。
3. `BasePolicy`：普通 BC 基准策略，由 `encoder + MLP trunk + head` 组成；残差
   SAC 只通过 `load_base_policy()` 加载和冻结它，不复用 `PolicyNet`。
4. `LSTMGMPolicy`：同一基准策略模块中的 LSTM + diagonal GMM 策略，提供
   `distribution()`、`log_prob()`、`loss()` 和确定性 `mean_action()`。

普通 SAC 统一使用 `PolicyNet`，避免旧模型和旧
实验脚本立即失效；新的 BC 训练和残差基座已经使用 `BasePolicy`。新 BC
checkpoint 的 `policy_cfg.json` 会记录 `cnn_channels` 和 `cnn_kernel_size`，
残差 SAC 加载时会按配置重建相同的 encoder。

## 训练机制

- BC：对 `BasePolicy.mean_action()` 与专家动作做 MSE，和原训练器接口兼容。
- 残差 SAC：按 `policy_cfg.json` 冻结 `BasePolicy` 或 `LSTMGMPolicy`；残差 actor/critic 仍使用自己的模块，
  通过基座输出和当前帧表示交互。
- GAIL：判别器仍只看当前 Markov 状态/动作；它不应重复拥有 BC 的时序
  encoder，否则会破坏当前 replay 中的 `(s,a)` 契约。
- LSTM-GMM：示范动作有多峰时使用 `-log p(a|o_{1:T})`；确定性部署使用
  mixture weights 加权的 mode means。

普通 BC 默认仍使用动作均值的 MSE。只有同时训练 `log_std` 并设置
`loss_mode="gaussian_nll"` 时，Gaussian head 才有统计意义；单峰连续动作
示教不应默认启用 SAC 的 gSDE。若同一观测对应多个明显不同的合理动作，优先
使用 `LSTMGMPolicy`。
